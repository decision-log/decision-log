# AI에게 결정 권한을 주지 않으며, 그래서 로그를 작업 repo 밖 MCP 뒤에 둔다

AI는 함께 일하는 파트너이지 결정권자가 아니다. 읽기·후보 생성·재열기는 허용하고, **이슈를 결정하는 것은 허용하지 않는다.**

이슈를 결정하는 것은 "우리가 이렇게 합의했다"고 주장하는 행위다. AI는 그 자리에 없었으므로 주장할 자격이 없다. AI가 결정할 수 있으면 팀이 한 번도 함께 본 적 없는 문장이 팀의 결정으로 남는다. 반대로 재열기는 아무것도 파괴하지 않으므로(기존 답은 근거로 남는다) 넓게 허용해도 안전하다.

## 저장 위치가 여기서 파생된다

로그가 작업 repo 안에 파일로 있으면 AI가 그 파일을 직접 편집할 수 있고, 도구 표면에서 막아둔 경계가 그대로 우회된다. **프롬프트로 하는 부탁은 강제가 아니다.** 그래서:

- 로그는 작업 repo **밖** 팀 공용 서버에 둔다
- AI의 유일한 통로는 MCP이며, **결정 연산은 아예 제공하지 않는다**

## 왜 마크다운 파일이 아닌가

"내용을 다시 입력하지 않는다"는 편의만 놓고 보면 repo 안의 마크다운 파일 하나로 충분하다. MCP를 쓰는 이유는 편의가 아니라 **권한 경계를 구조로 만들기 위해서다.** 편의만이 이유라면 이 결정은 과잉이다.
