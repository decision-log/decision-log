# STT 실측과 요건

실제로 재 본 것과, 그 실측이 요구하는 것만 적는다. 추측은 "확인하지 못한 것"에 따로 둔다.

## 실측 — 팀 용어가 깨진다

도구 없이 치른 팀 회의 나흘치를 기계로 옮겨 봤다. 팀이 매일 쓰는 말이 회의 내내 같은 식으로 깨졌다.

| 원래 말 | 옮겨진 표기 | 횟수 |
|---|---|---|
| 스크럼 | 시끄러움 | 6 |
| `.git` | 점기 | 8 |
| `.gitignore` | GD 근원 | 6 |
| 한 사람의 이름 | 원호 / 원훈 / 원우 | 회차마다 다름 |

깨진 표기는 표기만 보면 원형을 알 수 없다. 같은 오류가 두 모양으로 나타났다. `.git → 점기` 처럼 한 회의에서 전부 같은 형태로 깨지는 것과, `툴 콜링 → 툴 풀링 / 풀 콜링 / 툴 콜딩` 처럼 매번 흔들리는 것이다. 흔들리는 쪽은 같은 말인지도 알아보기 어렵다.

고칠 방법은 인식기에 팀 용어를 미리 넣는 것이고, 실측 당시 아무도 넣지 않았다. 이유는 **"매번 우리 맥락에 맞춰 써서 넣는 게 번거로워서"** 였다.

## 요건

| | 요건 | 왜 |
|---|---|---|
| 1 | 파일 단위 비동기 전사 | 회의 종료 후 일괄 처리. 실시간은 하지 않는다 |
| 2 | 컨텍스트·용어 주입 | 위 실측. 이 기능이 없는 공급자는 깨진 표기를 고칠 길이 없다 |
| 3 | 구간 타임스탬프 | 이슈 후보에서 회의록의 어느 지점인지로 내려가는 경로 |
| 4 | 한국어 정확도 | — |
| 5 | 장시간 오디오 (1~2시간) | — |

화자 분리는 지금 요건이 아니다. 화면의 한 줄에 화자가 없다.

## 컨텍스트 주입의 두 형태

공급자마다 컨텍스트를 받는 모양이 다르고, 그 모양이 무엇을 넣을 수 있는지를 정한다.

| 형태 | 공급자 | 넣을 수 있는 것 |
|---|---|---|
| 자유 텍스트 | Whisper(224토큰), gpt-4o-transcribe | 문장. 용어 설명이나 "`.gitignore`는 깃이그노어로 발음한다" 같은 안내 |
| 키워드 목록 | CLOVA(1,000개), ElevenLabs(1,000×50자), AssemblyAI(1,000), Deepgram(500토큰) | 단어·짧은 구만 |

키워드 목록형은 구를 통째로 못 넣는다. CLOVA 문서가 명시한다 — *"여러 단어들이 조합된 구문일 경우 해당 구문이 아니면 부스팅의 영향을 받기 어려움."*

주입은 거꾸로도 돈다. 목록에 `Caddy` 가 있으면 "응답 **캐시**"가 "응답 **Caddy**"로 나올 수 있다. 얼마나 자주 나는지는 아직 재지 않았다.

## 한국어 정확도 — CER

`회의` 열이 우리 조건에 가장 가깝다. 낮을수록 좋다.

| API | Avg CER | 회의 |
|---|---|---|
| Return Zero (RTZR) | 5.91 | 6.74 |
| RTZR Whisper | 6.59 | 8.33 |
| Naver CLOVA Speech | 7.52 | 7.63 |
| ETRI | 10.19 | 10.56 |
| Azure batch STT | 10.88 | 9.95 |
| AWS Transcribe | 11.11 | 9.65 |
| OpenAI Whisper | 11.39 | 10.16 |
| Google API v2 | 11.50 | 11.62 |
| Gemini 2.0 Flash | 16.58 | 11.98 |
| Deepgram nova-2 | 21.02 | 17.8 |

출처: [rtzr/Awesome-Korean-Speech-Recognition](https://github.com/rtzr/Awesome-Korean-Speech-Recognition)

RTZR 이 만든 벤치마크고 RTZR 이 1등이다. gpt-4o-transcribe, ElevenLabs Scribe v2, AssemblyAI Universal-3.5, Deepgram nova-3 는 빠져 있다. 읽을 수 있는 신호는 하나다. 한국어에서 국산과 글로벌 범용의 격차가 크고, 그 차이는 대부분 고유명사와 조사에서 난다.

## 지금 쓰는 것

**OpenAI gpt-4o-transcribe.** 자유 텍스트 컨텍스트를 받아서다. 한국어 기본 정확도는 CLOVA 보다 나쁠 가능성이 크지만, 깨진 표기를 문장으로 고쳐 줄 수 있는 쪽이 이 제품의 실측 문제에 맞는다.

| 한도 | 값 |
|---|---|
| 파일 크기 | 25MB |
| 파일 길이 | 1,500초 (25분). 넘기면 400 |

한 시간 녹음은 그대로 못 보낸다. ffmpeg 로 잘라 조각마다 전사하고 이어붙인다.

같은 계열의 새 모델 `gpt-transcribe` 가 분당 $0.0045 로 25% 싸다. 길이 한도가 같은지는 문서에서 찾지 못했다.

## 비용

한 시간 회의 기준 전사 $0.4 안팎. 넉 벌 전부가 커피 한 잔 값이다. 품질만 보고 고른다.

## 우리가 가진 것

팀 회의 녹음본 넉 벌. M4A, 가장 큰 것이 25MB. 시간순으로 한 벌씩 돌린다.

## 나중에 잴 것

같은 녹음으로 같은 조건에서 비교한다.

1. 컨텍스트 없이 전사 → 기본 품질
2. 팀 용어를 컨텍스트에 넣고 전사 → 깨진 표기가 사라지는지
3. 2번 결과에서 주입한 어휘로 잘못 끌려간 곳을 센다

2번이 핵심이고, 3번은 2번의 이득에서 빼야 할 값이다. 지금은 1번만 한다. 컨텍스트를 넣는 기능이 아직 없다.
